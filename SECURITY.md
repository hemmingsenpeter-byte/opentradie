# Security policy

OPENTRADIE v0.1 is pre-release software. It has had no external security audit.

Report suspected vulnerabilities privately through GitHub's "Report a vulnerability" (private security advisory) on this repository. Do not open a public issue, and do not include credentials, customer data or message bodies in any report.

The threat model, controls and residual risks are in [docs/SECURITY.md](docs/SECURITY.md).
