# Roadmap

Phases A to E from the brief are delivered through twelve milestones. Each milestone is a GitHub issue (see `.github/opentradie-issues.json`). Current status is in the README (reconciled against the merged code on 2026-10-19).

| #   | Milestone                | Scope                                                                                 | v0.1 status                                                                                                                             |
| --- | ------------------------ | ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Portable foundation      | Workspaces, schema, auth, tenant scope, CI, docs, ADRs                                | Done for v0.1: workspaces, schema, auth, tenant scope, ADRs; CI configured, see Actions                                                 |
| 2   | OpenClaw integration     | Gateway client adapter, mock, smoke procedure, tools-denied Gateway guidance          | Adapter and mock implemented; real adapter tested only against a fake gateway, never a live one                                         |
| 3   | Business data and memory | Customers, jobs, notes, search, knowledge items with provenance, optional embeddings  | Implemented: customers, jobs, notes, communications, text search, knowledge items; embeddings optional (pgvector path untested locally) |
| 4   | Quote workflow           | Enquiry, job, deterministic draft quote, approval, audit                              | Implemented and tested: the first vertical slice (API, web, Playwright)                                                                 |
| 5   | Local deployment         | Mac mini guide, launchd, Ollama                                                       | Scaffolded; unverified on hardware                                                                                                      |
| 6   | Cloud deployment         | Image, Compose, managed Postgres, S3, HTTPS                                           | Scaffolded; never deployed                                                                                                              |
| 7   | Hybrid connectivity      | Relay contracts, tunnel/relay options, single-authority guards                        | Single-authority guards and relay harness implemented and tested; no public relay                                                       |
| 8   | Email integration        | Normalised inbound, drafts, approval before send, Gmail OAuth                         | Planned                                                                                                                                 |
| 9   | Xero integration         | AccountingProvider, test adapter first, Xero only with credentials and real API tests | Planned                                                                                                                                 |
| 10  | Speech interface         | Contracts, whisper.cpp, iOS Shortcuts                                                 | Planned                                                                                                                                 |
| 11  | Security hardening       | Audit of controls, MFA, log-redaction tests, secret scanning, external review         | Planned                                                                                                                                 |
| 12  | Migration tooling        | Automated version of the 11-step procedure                                            | Planned (backup/restore test only in v0.1)                                                                                              |

Not in scope for v0.1: multi-tenant orchestration, billing, public relay, marketplace, mobile apps. Licence: proprietary commercial ([ADR 0010](adr/0010-proprietary-commercial-licence.md)).
