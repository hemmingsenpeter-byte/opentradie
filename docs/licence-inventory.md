## Procedure for a new dependency

1. Record the proposed package, version, release date and licence string here in the same pull request.
2. Refuse GPL, AGPL, LGPL, SSPL or unknown licences; ask the owner before any copyleft addition (AGENTS.md).
3. Pin exactly in the catalog; run `pnpm install`; commit the lockfile.
4. Run `pnpm licenses list --prod` and add the result to the release notes.
